# Sample input location

Place two manually supplied PNG or JPEG images here with these exact names:

- `frame_t0.png` — earlier observed frame.
- `frame_t1.png` — later observed frame.

FrameFlow does not download or fabricate satellite imagery. If these files are
absent, run the CLI with your own paths; the absence is reported as a clean
missing-image error. Any generated midpoint must be treated as **AI GENERATED**
and not as a real satellite observation.
