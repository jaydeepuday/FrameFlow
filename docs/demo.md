# Demo framing

FrameFlow is an observational/demonstrative interface for examining a
plausible temporal midpoint. Every generated file and UI result is marked
**AI GENERATED**. The midpoint must not be presented as a real satellite
observation and the system makes no disaster-prediction claim.

The confidence map is labeled **Model confidence proxy based on
interpolation/reconstruction consistency**. Its Low/Medium/High colors are
interpretable consistency bands, not calibrated probabilities.
